# Data directory (GSE163577)

Everything here except this README is git-ignored. Every file can be regenerated by `scripts/run_all.py`.

| Path | Content | Produced by |
|---|---|---|
| `GSE163577_RAW/` | 25 GEO filtered 10x matrices (`GSM4982083`–`GSM4982107`, `*_filtered_feature_bc_matrix.tar.gz`); download from GEO | — |
| `processed/qc_counts.h5ad` | All QC-passing singlets, raw counts, no down-sampling | `01_qc_doublets.py` |
| `processed/integrated.h5ad` | Log-normalised + `layers['counts']`, Harmony / UMAP / Leiden, `cell_type` | `02_integrate_annotate.py` |
| `processed/pseudobulk/` | Per-sample × cell-type summed counts and nuclei numbers | `04_pseudobulk_de.py` |
| `processed/subclusters_<CellType>.h5ad` | NVU sub-clustering objects | `05_fig2_deep_dives.py` |
| `genesets/*.gmt` | Enrichr libraries: MSigDB_Hallmark_2020, GO_Biological_Process_2023, Reactome_2022 | downloaded once from maayanlab.cloud |
| `41586_2021_4369_MOESM2_ESM.xlsx` | Yang *et al.* 2022 *Nature* Supplementary Table 1 (donor age, sex, PMI, Braak, CERAD, APOE, neuropathology); user-supplied | read by `10_donor_covariates.py` |
| `annotation/` | Cached UniProtKB and STRING v12 API responses | `08_fig5_target_prioritization.py` |

The `.rds` objects left from the legacy R pipeline (`seurat_*`, `cellchat_*`, `fig2_results_cortex.rds`,
`subclusters_*.rds`) are not used by the current pipeline. They hold down-sampled data (5,000 / 3,500 nuclei
per sample) and are kept only so that the legacy figures can be traced.

`41467_2022_34932_MOESM1_ESM.pdf` is the supplement of an unrelated GWAS method paper (GhostKnockoff, *Nat. Commun.* 2022). It contains no GSE163577 donor data and is not used.
